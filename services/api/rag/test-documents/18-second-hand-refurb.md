# 星桥商城二手与翻新商品说明

平台“星桥二手”与“官方翻新”是两条独立渠道。官方翻新由星桥自营的翻新中心检测、清洁并更换易损件后出售，享受与新品相同的一年整机质保，但外观可能有轻微使用痕迹。星桥二手为个人与商家之间的寄售或担保交易，商品成色由卖家标注，平台作为担保方介入验机与交易资金托管。

二手商品成色分为全新仅拆封、95 新、9 成新、8 成新及以下四档，成色判定以验机报告为准。验机报告包含电池效率、外观划痕、功能检测项目与是否拆修记录，买家下单后可在线查看。官方验机服务覆盖手机、平板、笔记本、相机与部分家电，验机费由卖家承担。

二手交易的售后原则是“一机一议”。支持“七天无理由”的商品会在页面明确标注；未标注的商品适用“描述不符可退”规则：实物与描述或验机报告不符、存在未披露的重大瑕疵（如进水、主板维修、屏幕更换）时，买家可在签收后 7 天内申请退货。个人卖家非质量问题退货需与卖家协商，平台不强制卖家接受无理由退货。

资金安全方面，二手交易采用确认收货后放款。买家确认收货或系统自动确认（签收后第 10 天）后，货款才会结算给卖家。交易争议由平台客服介入仲裁，卖家需在 48 小时内响应并提供凭证，逾期未响应则倾向支持买家诉求。翻新商品享受 7 天无理由退货与一年质保，退货与换货走自营渠道，无需卖家介入。

二手商品不参与价格保护、会员积分抵扣与部分优惠券。分期购买二手商品仅支持官方翻新与平台自营二手。账号绑定、激活锁未解除的设备不予上线交易，验机发现即下架并退还卖家寄送时产生的运费。
