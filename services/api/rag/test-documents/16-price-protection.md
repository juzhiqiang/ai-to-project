# 星桥商城价格保护与价保规则

价保护覆盖自营商品与部分第三方商品。用户在签收后 15 天内，若同商品发生降价，可在“我的 - 订单 - 申请价保”中发起，系统自动比对下单时的成交价与当前售价，差价以等额优惠券形式返还，不直接退现金。价保仅支持一次申请，以发起时刻的商品价格为准。

享受价保需满足以下条件：商品数量与规格一致、订单已完成支付且未退款、商品处于价保时效内。叠加了限时秒杀、新人专享或仅限部分地区价格导致的降价，不属于价保范围。使用满减券购买导致的实际成交价已低于吊牌价时，系统按实付金额与当前售价的差额计算，而不是按吊牌价计算。

大型促销（如 618、双 11、年货节）期间，平台推出“全网价保”承诺，用户可申请与其他授权渠道对比后的差价补偿，需提供对比平台的商品链接与实付截图。全网价保适用于同品牌、同型号、同规格商品，且对比渠道需为品牌方或官方授权店铺。

差价返还的优惠券形式与满减券一致，可在后续订单中抵扣，有效期通常为 90 天。返还优惠券不可提现、不可转让、不可购买礼品卡。若订单已申请价保后又发生退货，已返还的价保券会同步收回；券已被使用且订单退货时，对应金额从退款中扣除。价保申请通常在提交后 1 个工作日内完成审核，结果通过 App 消息与短信双通道通知。
