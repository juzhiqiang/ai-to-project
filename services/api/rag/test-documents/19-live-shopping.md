# 星桥直播购物与达人带货规则

直播间的商品与商城常规商品共享同一套交易与售后系统，但部分商品为直播间专属价或秒杀价，活动结束后即恢复常规售价。用户在直播间下单，订单与普通订单同样计入会员成长值，也支持评价、晒单与积分。直播间专属价不参与价格保护，降价属于限时活动性质。

达人带货的商品由商家发货，责任主体为对应商家。若商品存在质量问题，买家可先联系商家客服处理；商家怠于处理或不响应时，可向平台申诉，平台将依据《网络交易纠纷处理规范》介入。达人通过直播承诺赠品、优惠而未兑现的情况，买家需保留直播录屏与订单截图作为凭证提交平台核实。

直播间抽奖与福利适用于“直播间内下单并支付成功”的用户。中奖用户需在 7 个自然日内填写收货信息，逾期视为放弃；实物奖品通常 15 个工作日内寄出，虚拟奖品（优惠券、积分等）发放到下单账号。优惠券类奖品有效期从发放之日起计算，具体见卡券详情。

未成年人打赏与冲动消费受到平台保护。监护人发现未成年人在直播间未经许可消费的，可凭监护人身份证明、关系证明与消费记录，在“未成年人消费申诉”通道申请退款。平台核实属于未成年消费且尚未发货的，优先办理退款；已发货的按无理由退货政策处理，特殊商品除外。

直播间商品评价与普通商品评价规则一致，但平台对刷单、虚假交易、恶意差评有更严格的风控。参与直播拼单、帮好友砍价等活动的订单，若最终未支付成功，不计入活动统计。直播回放不会永久保留，商家主播需自行留存交易承诺记录以备争议处理。
