# 星桥商城家装家电配送与安装服务

大件商品（冰箱、洗衣机、空调、电视、家具等）配送与普通商品不同。下单时系统会根据地址自动匹配“送达即装”或“送装分离”两种模式。空调、热水器等涉及管路线路改造的商品采用送装分离，配送员送达后 48 小时内由持证工程师上门安装；冰箱、洗衣机、电视等支持送达即装，安装工随货上门，用户无需二次预约。

安装费用按地区与商品类目收取，墙面打孔、加长管线、高空作业等会额外计费，工程师上门前会出示标准价目表。用户可在订单页预约安装时间，时间窗口通常为上午、下午、晚间三个档位。已预约时间如需改期，请提前 3 小时以上操作，否则可能产生空跑费。送货上门范围仅限地址所在楼层，楼梯房 4 层及以上、无电梯时可能会按件收取楼层搬运费。

大家电开箱验机建议在工程师在场时进行。通电前请检查外观是否有磕碰、划痕、缺件；发现明显外观损伤要求当场在工单上注明，必要时拍照留存，作为后续换货或补偿依据。已通电试机后出现性能故障，7 天内可按“性能故障”申请换货，换货优先发同型号，缺货时可补差价换购或退款。

送货时效：一二线城市大家电一般 3 至 5 个工作日，自营仓有现货时可能次日达，用户可选叠加“急速达”服务。配送员上门前会电话确认，临时无法收货可改约，改约不额外收费但影响整体时效。大家电非质量问题退货需承担往返运费与安装拆卸费，且外包装缺失会影响二次销售评估，可能被拒收退货申请。

家电以旧换新服务支持旧机折价抵扣，旧机由回收人员上门评估并现场结算，折价金额以优惠券形式发放到账户，有效期 60 天。延保服务可在线购买，整机延保最长可延长 3 年，延保期内维修免上门费与配件费，但人为损坏、私自拆机除外。
