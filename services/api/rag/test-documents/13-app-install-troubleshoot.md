# 星桥商城 App 安装与常见故障排查

本文是虚构品牌“星桥商城”的内部测试资料。App 支持 iOS 14 及以上、Android 9 及以上的系统，最低需要约 180MB 可用存储空间用于安装，首次登录会额外下载 30MB 左右的必要资源包。在应用商店搜索“星桥商城”即可下载，请认准开发商名称“星桥网络科技有限公司”，避免从第三方不知名渠道安装来路不明的安装包。

下载缓慢或安装失败，请先切换 Wi-Fi 与移动网络对比，并确认系统剩余空间充足。Android 用户若提示“安装包与设备不兼容”，多为系统版本过低或关闭了“允许安装未知来源应用”；iOS 用户安装卡在“等待中”时，可尝试重启设备或退出并重新登录 Apple ID。安装包已下载但无法安装时，删除后重新下载通常可解决。

启动闪退或白屏，先尝试强制退出 App 后重新打开；仍无效则检查是否为旧版本，前往应用商店更新到最新版本。清除缓存不会删除订单与收货地址等数据，只会清理图片与活动页等临时文件，可在“我的 - 设置 - 清除缓存”中操作。若长时间停留在启动页，可尝试在飞行模式下打开一天时间转区观察，或检查系统时间是否手动改成了错误日期导致证书校验失败。

网络异常提示“连接超时”或“加载失败”时，先确认是否开启了 VPN、代理或省电模式，这些可能拦截 App 的网络请求。切换网络后仍无法登录，可在登录页点击“紧急求助”获取临时验证码入口。Android 通知收不到时，检查是否误关了系统通知权限或厂商后台自启动限制；iOS 用户请确认“通知”与“后台 App 刷新”均为开启状态。

定位用于配送地址填写与附近门店展示，可在首次安装时关闭，之后随时在系统设置中开启。App 内“关于与帮助 - 客服直达”可一键跳转在线客服。连续 5 次登录失败会临时锁定账号 30 分钟，可等待后重试或通过短信找回密码。
