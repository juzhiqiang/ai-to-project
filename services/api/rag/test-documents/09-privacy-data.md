# 星桥商城隐私与数据管理说明

商城为完成交易会处理账户标识、联系方式、收货地址、订单商品、支付状态、售后记录和设备安全信息。银行卡完整卡号由持牌支付机构处理，商城仅保存支付渠道、交易流水号和脱敏卡号。个性化推荐使用浏览、收藏和购买行为，用户可以在隐私设置中关闭个性化推荐，关闭后仍会看到非定向商品内容。

用户可在线申请导出账户资料，导出包通常在 7 个工作日内生成，包含基本资料、地址簿、订单和售后记录，不包含其他用户信息、内部风控模型和依法不能披露的安全日志。为防止冒领，下载链接有效期 72 小时，并需要再次验证身份。频繁申请导出可能受到每 30 天一次的限制。

账户注销完成后，非必要的个人资料会删除或匿名化。根据财税和交易合规要求，订单、发票和支付凭证保存 5 年；售后维修记录保存 3 年；账户安全日志保存 180 天；客服录音保存 90 天，存在投诉或诉讼时可延长至争议结束后 1 年。保存期届满后按批次删除，因此页面不可见与底层完成清理可能存在时间差。

商城可能向承运商提供姓名、电话和地址以完成配送，向维修服务商提供设备型号和故障描述以完成售后。合作方只能为指定目的处理数据。用户认为资料不准确时可申请更正；涉及订单主体、发票抬头或已完成支付记录的关键字段不能直接覆盖，只能通过更正记录保留审计轨迹。隐私投诉将在 2 个工作日内确认受理，复杂请求 15 个工作日内答复。
