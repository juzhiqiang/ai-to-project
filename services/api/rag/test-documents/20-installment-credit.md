# 星桥商城分期付款与信用服务说明

平台与多家持牌金融机构合作提供分期服务。订单金额满 300 元即可选择分期，支持 3 期、6 期、12 期、24 期，部分活动商品标注免息分期。免息由商家或平台承担利息补贴，用户实际还款金额等于商品价格，不存在隐藏手续费；非免息分期的手续费率在收银台明确展示，按分期期数一次性计入每期账单。

分期订单退款与账务处理：退货退款成功后，已还期款项原路退回，未生成账单的分期自动取消，剩余应还义务终止。已产生的分期利息按实际占用天数计算，全额退款时利息同步退还，部分退款时利息按比例调整。分期申请失败的常见原因包括额度不足、征信未通过、短期内申请次数过多等，失败后可改用其他支付方式，不影响订单提交。

信用服务包括“先用后付”与“星桥白条”。先用后付允许用户先下单后付款，签收后第 15 天系统自动扣款，期间可自助还款。星桥白条为平台信用支付产品，额度由合作机构根据用户信用评估授予，可用于支付绝大多数自营与第三方商品，不支持用于购买礼品卡、虚拟充值与跨境订单。

逾期影响：分期与白条逾期会产生逾期费用，并可能影响合作金融机构的征信记录。用户可通过“我的 - 星桥金融”查询账单日、还款日与应还金额，也可设置自动还款。还款日遇法定节假日时以机构实际扣款安排为准，请提前确保绑卡余额充足。

关闭分期服务：用户还清全部欠款后可在金融页申请注销分期与白条额度。注销需满足无未结清账单、无进行中的争议工单。分期购用的商品出险、退货产生的退款，均优先冲抵未还账单，再退剩余部分到原支付账户。
