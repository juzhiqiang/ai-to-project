# 星桥客服、工单与投诉处理时限

在线机器人提供全天服务，人工在线客服时间为每日 8:00 至 24:00，电话客服时间为每日 9:00 至 21:00。普通咨询目标为 30 分钟内首次响应；金星会员进入优先队列，黑钻会员可使用专属客服，但优先响应不代表问题一定在首次会话中解决。夜间提交的非紧急人工工单从次日 8:00 开始计算时限。

物流核查、优惠争议和普通售后工单应在 1 个工作日内首次反馈；发票红冲、信用卡退款核查和高价值商品检测可在 3 个工作日内反馈。首次反馈可能只是告知调查进度，不等于最终解决。客服承诺的具体回电时间会记录在工单中，超过约定时间 2 小时仍未联系，用户可申请升级。

投诉分三级：一般服务态度或流程投诉为三级，2 个工作日内答复；涉及重复扣款、商品安全隐患或金额超过 5,000 元的争议为二级，4 个工作小时内联系并在 3 个工作日内给出方案；疑似账户盗用、大规模数据泄露或人身安全风险为一级，安全值班团队 30 分钟内响应。工作日是周一至周五，不含法定节假日。

升级投诉需要提供订单号、问题经过、期望方案和可联系时间。用户重复创建相同工单不会缩短时限，系统会合并处理。若对最终方案不满意，可在工单关闭后 7 个自然日内申请一次复核，复核由不同处理人员执行，预计 3 个工作日完成。客服无权绕过实名验证、直接修改银行退款账户或承诺违反商品页规则的赔偿。
